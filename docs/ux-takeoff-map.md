# UX-карта takeoff-сценария: Foreman (US) → инструмент для РФ

Источник: триал foreman.co, снято 2026-10-20 через встроенный браузер и REA
(`capture_browser_scenario`, без тел запросов и заголовков). Тестовый файл —
синтетический план `storage/demo/demo_plan_OV.pdf`, данных заказчика нет.

## 1. Как устроен сценарий у Foreman

| Шаг | Экран / URL | Что делает пользователь | Что показывает система |
|---|---|---|---|
| 1 | `/dashboard/projects` | Выбирает проект на доске Lead / Sold / In Progress / Complete | Постоянная панель AI-ассистента справа |
| 2 | `…/projects/<id>` → вкладка **Files** | Загружает PDF (Upload File / Upload Folder / drag-and-drop) | Строка файла: тип «Plan set», `N pg · M meas`, размер, дата; колонки **Takeoffs** и **Markups** |
| 3 | `/editor/<file>?projectId&page=1&kind=plan` | Открывает файл кликом | Полноэкранный редактор: назад, имя файла, меню **Takeoffs**, инструменты **Select / Area / Linear / Count**, выбор масштаба, undo/redo, поворот, зум, сворачиваемая панель **Annotations** |
| 4 | Тот же редактор | Выбирает масштаб из списка (`1-1/2" = 1'` и т. п.), ставит измерения | Измерения хранятся как аннотации, сгруппированные по takeoff-группам |
| 5 | Budget | Квантити переходят в строки бюджета с ценой из каталога | Цепочка «чертёж → смета → договор → счёт» |

Что видно из API при открытии редактора (только метод и путь):

- `GET /uploads/<file>/pages`, `/legend`, `/legend/detections`, `/room-detections`,
  `/openings`, `/ai-review` — серверный разбор листа (помещения, проёмы, легенда).
- `GET /takeoffs`, `/takeoff-measurements`, `/annotation-groups?groupType=takeoff|markup`,
  `/markups`, `/plan-versions` — модель измерений, группы и версии листа.
- `GET /api/assistant/conversations|history` — ассистент живёт на уровне сессии, не листа.
- Аналитика: PostHog, Sentry (вынесена наружу, в РФ нужно заменить/отключить).

## 2. Что у Foreman хорошо (брать)

1. **Файл как точка входа**: колонка Takeoffs в списке файлов показывает прогресс
   измерений без открытия документа.
2. **Один редактор вместо мастера**: загрузил → открыл → мерь. Нет промежуточных настроек.
3. **Связь измерения с листом**: каждая величина помнит свой лист.
4. **Группировка измерений** (annotation groups) и версии листа.
5. **Постоянный ассистент рядом**, но не вместо инструментов.

## 3. Что у Foreman слабо (наш зазор)

| Наблюдение | Следствие для РФ-продукта |
|---|---|
| Инструменты общие: Area / Linear / Count. Нет понятия «система», «сечение», «изоляция» | Основная сущность — **участок воздуховода** со свойствами (система, сечение, изоляция, длина) |
| Масштаб вручную из американского списка (`1-1/2" = 1'`) | Определять масштаб автоматически (у нас уже есть) и показывать как 1:100 |
| AI-слой ориентирован на помещения и проёмы (room/openings detection) | Для ОВ ключевое — трассы и подписи, а не комнаты |
| Нет сверки со спецификацией чертежа | **Сверка с ведомостью ОВ-СП** — главное отличие: «цифра взята с этого отрезка, лимит по спецификации такой-то» |
| Выгрузка в основном в их бюджет/QuickBooks | Excel/XLSX, сметные программы, позже 1С |
| На тесте файл с нашими выносками открылся с выносками-диагоналями, которые легко принять за воздуховоды | Отдельный слой выносок/подписей, чтобы не мерить лишнее |

## 4. Предлагаемый сценарий для РФ (MVP, UX first)

1. **Загрузка** PDF проекта ОВ (один или комплект) → прогресс разбора на карточке.
2. **Экран «Листы»**: миниатюры листов с авто-определением: тип (план / схема / спецификация),
   масштаб, число найденных участков. Спорные листы подсвечены.
3. **Экран листа**: чертёж слева, справа таблица «Система · Сечение · Изоляция · Длина, м».
   Клик по строке подсвечивает отрезки на чертеже, и наоборот. Цвет = система.
4. **Сверка со спецификацией**: у каждой системы показаны «измерено / по спецификации / Δ»;
   превышения помечены. Это экран доверия.
5. **Правки**: перенести участок в другую систему, поправить сечение, исключить участок.
   Все правки обратимы (undo) и отражаются в итогах сразу.
6. **Выгрузка**: XLSX (формулы SUM) и CSV под русскую локаль — уже реализованы в
   `dc_extraction.takeoff.report`.

Ассистент — вторичен: «почему В2 больше спецификации?», а не основной вход.

## 5. Адаптация под РФ (кратко)

- Масштабы и единицы: 1:50 / 1:100 / 1:200, метры и миллиметры, сечения `400x200`, `Ø200`
  (кириллические `х` и `Ф` нормализуются — это уже есть).
- Документы: ведомость ОВ-СП как эталон сверки; позже КС-2/КС-3, УПД.
- Данные: хранение и обработка в РФ (152-ФЗ), без внешней аналитики (PostHog/Sentry заменить
  на локальные аналоги), локальная VLM только для легенд и растровых листов.
- Цена: ориентир 3–10 тыс. ₽/мес по документу-разбору.

## 6. Что не проверено

- Как Foreman строит измерения автоматически («AI измеряет чертёж»): на синтетическом файле
  видно только «1 pg · 2 meas» и пустой список групп, ответы API не читались (тела не
  захватывались намеренно).
- Тарифные ограничения и поведение на больших комплектах.
- Экспорт из takeoff в Foreman.
