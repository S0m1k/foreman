# Foreman — дизайн-система

Рабочий инструмент сметчика: ведомость объёмов по векторным PDF инженерных систем.
Экраны, в которых работают часами, а не страницы, которые листают. Отсюда всё ниже.

Основа — стиль **framed sheet** из taste-skill (`.claude/skills/taste-skill`, `library/app.json`) и
правила `references/app-screens.md`; ориентиры — IBM Carbon (плотные таблицы, Plex), Linear
(спокойная навигация), Airtable (работа с таблицей), Vercel (точная типографика)
(`.claude/skills/awesome-design-md/*.DESIGN.md`).

## Идея

Оболочка — одна тонированная рамка цвета чертёжной кальки; работа лежит на белом листе с
тонкой кромкой. Цвет живёт только на данных, и это **цвета самих чертежей ОВ**: приток
красный, вытяжка синяя, дымоудаление зелёное, подпор оранжевый. Сметчик узнаёт систему на
экране тем же цветом, что и на листе.

- **Знак продукта** — условное обозначение вертикального воздуховода на плане
  (квадрат с диагоналями).
- **Фирменный элемент** — штамп листа в шапке редактора: шифр, лист, масштаб, как в
  основной надписи по ГОСТ 21.101.
- **Вопрос каждого экрана** — пишется до вёрстки (см. «Экраны»).

## Токены

Все значения — CSS custom properties в `apps/web/src/app/globals.css`. Компоненты ссылаются
только на токены.

| Роль | Токен | Значение |
| --- | --- | --- |
| Рамка (сайдбар, верх) | `--ground` | `#eef2f5` — калька |
| Лист, карточки | `--surface` | `#ffffff` |
| Ступень внутри листа | `--raised` | `#f5f7f9` |
| Активный пункт, выбранная строка | `--active` | `#e4e9ee` |
| Кромка листа и карточек | `--border` | `#e3e7eb` |
| Линия строки таблицы | `--rule` | `#eef1f4` |
| Кромка контрола | `--control` | `#c9cfd6` |
| Текст | `--text` | `#141619` |
| Вторичный текст (4.5:1) | `--muted` | `#5b6168` |
| Третий уровень, плейсхолдеры (4.5:1) | `--faint` | `#6b7078` |
| Основное действие | `--primary` | `#141619`, белая подпись |
| Хорошо / плохо / внимание | `--positive` `--negative` `--warning` | `#1e7b4f` `#c4242a` `#92400e` |
| Пилюли (фон / текст) | `--pill-*-bg/ink` | зелёная, красная, янтарная, нейтральная пары |
| Сетка графика | `--grid` | `#e5e8ec` |

**Цвета систем** (данные, не хром), ≥ 3:1 на белом: П `hsl(4 72% 46%)`, В `hsl(214 70% 44%)`,
ДВ `hsl(145 55% 32%)`, ПД `hsl(30 85% 38%)`, ДП `hsl(280 35% 42%)`. Внутри семейства система
получает свою светлоту (В1 и В2 различимы). Больше четырёх оттенков на экране — только когда
на листе действительно столько семейств.

## Типографика

Один гротеск — **IBM Plex Sans** (есть кириллица и табличные цифры). **IBM Plex Mono** — только
для идентификаторов и кодов. Цифры везде табличные (`.num`), числа в колонках — вправо.

| Роль | Размер / вес |
| --- | --- |
| Заголовок экрана (h1) | 22 / 600 |
| Заголовок блока | 16 / 600 |
| Ведущая цифра экрана | 28 / 400 |
| Текст, ячейки, навигация | 14 / 400, интерлиньяж 20 |
| Подписи, метки, оси | 12 / 400, серые |

Регистр — предложение. Никаких мелких заглавных с разрядкой, никаких «надписей над заголовком».

## Поверхности, радиусы, отступы

- Рамка и лист: лист отступает 8px от правого и нижнего края окна, радиус 16, кромка 1px, без тени.
- Карточки: радиус 8, кромка 1px **или** ступень тона, никогда тень. Тень — только у того, что
  парит: меню, поповер, тост.
- Контролы: радиус 6, высота 32 (в формах 38).
- Шаг 4px. Зазор между карточками — один на экран: 16. Внутренний отступ карточки 20, листа 24.

## Компоненты

Классы в `globals.css`, React-обёртки в `apps/web/src/components/ui/`. Живая витрина —
**`/ui`**.

- **Кнопки** `.btn`: `.btn-primary` (почти чёрная, одна на экран), `.btn-secondary` (белая с
  кромкой), `.btn-ghost` (текст), `.btn-danger` (текст в цвете ошибки). Высота одна в ряду.
- **Пилюли** `.pill`: `pill-positive`, `pill-negative`, `pill-warning`, `pill-neutral`, `pill-info` —
  бледный фон и тёмный текст того же оттенка, 20px. Только в строке или рядом со значением.
- **Панель** `.panel` с `.panel-head` (заголовок слева, действие или период справа).
- **Таблица** `.table`: заголовки 12px серые без заливки и без капса, линии строк `--rule`, числа
  вправо табличными цифрами, отсутствие — серое тире, ноль — ноль.
- **Поле** `.field`: подпись над полем 14/500, поле белое с кромкой `--control`.
- **Сегменты** `.segmented`: дорожка `--raised`, активный — белый.
- **Состояния**: пустой блок хранит рамку и одну фразу; загрузка — серые бруски реального размера
  без мерцания; ошибка — внутри блока, одна фраза и «Повторить».

## Экраны и их вопросы

| Экран | Вопрос | Самое крупное |
| --- | --- | --- |
| Загрузка альбома | «Что сюда положить?» | Зона альбома ОВ |
| Проект | «Сходится ли проект со спецификацией и где нет?» | Сверка по системам + карточки планов |
| Лист | «Верно ли разнесены участки этого листа?» | Чертёж с участками; справа — системы листа |

## Запрещено

Градиенты, стекло и размытие, тени на покоящемся, иконки в цветных кругах, спарклайны на KPI,
зебра и заливка шапки таблицы, капс с разрядкой, моноширинный шрифт вне кодов, фиолетовый и
индиго, кремовый с терракотой, тёмный или насыщенный сайдбар на светлом экране, эмодзи,
плейсхолдерные данные.
